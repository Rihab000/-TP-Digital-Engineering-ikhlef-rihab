## 4. Bilan des commandes Git

- **git status :** permet de connaître l'état des fichiers du dépôt et de vérifier les modifications.
- **git remote -v :** permet d'afficher les adresses des dépôts distants configurés.
- **git log --oneline --graph --all :** permet de visualiser l'historique des commits et les différentes branches sous forme de graphe.
